# Project intent

Livework explores an app that can evolve itself in public. A person should be able to make a situated request in the actual product, see what the system is doing, understand why it changed, and inspect the result. Eventually the system may also originate proposals when it can explain their rationale and earn trust through evidence.

The live-chat MVP is deliberately modest. It proves the substrate first: multiple people share one real-time room with durable history and a common view of work. That same room is the natural place for a change request and its public activity record.

Speed matters because feedback is the product. A request should be acknowledged immediately, progress should be legible while work is happening, and the final result should be easy to verify. Minimal visible status matters for the same reason: the product should feel like a useful chat surface, not a control room built around the machinery.
